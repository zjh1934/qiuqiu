# 球球 —— 拾字 + 放大镜 二合一

一个悬浮球，两种本事，**互不干扰**：

| 操作 | 干什么 |
|---|---|
| 轻点球 | 球变绿，进入"选字"状态 |
| 再点屏幕上的字 | 从那一句开始往下读 |
| 朗读中轻点球 | 停止 |
| 按住球不动 | 放大，手指挪动画面跟着走 |
| 拖动球 | 挪球位置 |
| 闲置 2.5 秒 | 球自动变淡 |

**放大时不朗读，朗读时不放大。** 一按住要放大，朗读立刻停、选字态立刻取消——不交叉。

## 跟原来两个 APP 的区别

- **只要一个无障碍服务**（原来要"悬浮窗权限 + 无障碍"两个）
- 一个服务同时声明 `canRetrieveWindowContent`（抓字）和 `canControlMagnification`（放大）

## 权限

装完去 **设置 → 无障碍** 找到「球球」打开。就这一个。

## 编译（AIDE）

1. 用 AIDE 打开 `src` 这个目录
2. 直接 Build

### 可能遇到的报错

| 报错 | 改法 |
|---|---|
| `<queries> 未知元素` | 删掉 `AndroidManifest.xml` 里整个 `<queries>...</queries>` 块。引擎枚举有第二条路兜底，不影响 |
| `找不到 Build Tools 30.x` | 已去掉 `buildToolsVersion`，用 AGP 默认版本。若仍报，把 `compileSdkVersion` 改成 29 |
| `程序包 android.speech.tts.Voice 不存在` | 你的 SDK 低于 21，几乎不可能。真遇到就把 `TtsManager` 里 `listVoicesZhFirst` 的 `getVoices()` 那段删掉 |
| `程序包 R 不存在` | 界面是纯 Java 写的，只用了 `android.R`。加 `Build → Rebuild` |

## 文件说明

```
ComboService.java   唯一服务：手势分发 + 状态机 + 保活通知
BallController.java 手势判定（拖动 / 按住放大 / 轻点）
BallView.java       球的绘制，四态（待命/放大/选取/朗读）
ZoomController.java 系统放大控制
TextGrabber.java    抓字：多窗口取根 → 单趟收集 → 阅读顺序 → 精确到句 → 续读
TextLayout.java     纯排版逻辑（阅读顺序 / 断句），无 Android 依赖，可单测
TtsManager.java     TTS 引擎与音色管理
Prefs.java          设置读写
MainActivity.java   三个 Tab 的界面
```

## 球不显示？按顺序排查

1. **无障碍开了吗** —— 没开的话点开关是无效的，会直接带你去设置页。
   设置 → 无障碍 → 找到「球球」→ 打开
2. **看界面上那行状态** —— 现在会明确写出卡在哪一步：
   - `服务未运行（去系统设置开启无障碍）`
   - `球显示失败：BadTokenException: ...` ← 这个会把系统给的具体原因打出来
   - `球已显示`
3. **个别 ROM 加不进无障碍窗口** —— 代码会自动退到
   `TYPE_APPLICATION_OVERLAY` / `TYPE_PHONE`，
   前一条需要「悬浮窗」权限（manifest 里已声明，
   部分 ROM 还要在 设置→应用→权限 里手动给）。

窗口类型用的是**服务自己的 Context**，不是 applicationContext ——
这点很关键，用 applicationContext 建的无障碍窗口在多数 ROM 上加不进去。

## 运行日志

主界面第四个 Tab「日志」就是。出问题时导出给我，我能直接定位。

**界面上能做的：**
- 实时看最近 60 条（最新的在上面）
- 「导出到下载目录」→ 存到 `Downloads/球球日志_MMDD_HHmm.txt`
- 「清空日志」

**日志记什么：**
- `G/gesture` 手势时序 —— 按下、判定为拖球/放大、抬手时的位移
- `S/state` 状态变化 —— `待命 → 选取态 → 朗读中`
- `E/...` 错误，含堆栈
- 窗口类型尝试结果（`加窗口成功 type=2038` / `加窗口失败 → BadTokenException`）
- TTS 引擎枚举命中数、初始化结果

**不记什么：** 只记代码内部事件，不记你读到的任何文字内容
（只有一处例外：抓字成功时会记「抓到 N 字，开头：「…」」的前 20 字，用来确认抓的位置对不对）。

文件同时存在 APP 私有目录（界面上会显示路径），超过 200KB 自动砍掉前面一半。

## 查 bug 最快的方式

1. 复现问题
2. 主界面 → 日志 → 导出到下载目录
3. 把那个 txt 发我

开局那几行带设备信息（`SDK= 设备= 版本=`），一起发过来。

# 球球

原名「拾放」，改名「球球」。包名仍是 `com.floating.combo`（改包名要动目录和全部 import，风险大，显示名已改）。

## 这一版改了什么

### 1. 深色主题
背景 `#121212`、卡片 `#1E1E1E`、文字 `#E0E0E0`、强调色 `#64B5F6`。
manifest 主题也从 `Theme.Material.Light` 换成 `Theme.Material`。

### 2. 新 LOGO
不再是"一个圆加白边"，现在是这样：

- **外圈**：浅蓝细描边，给球一个边界
- **主球**：径向渐变（左上亮、右下深），做出玻璃球体积感
- **高光**：左上椭圆半透明白
- **内球**：同心白球，带极淡暗边，避免显得像贴纸

两套资源都给了：
- `mipmap-anydpi-v26/ic_launcher.xml` —— Android 8+ 用自适应图标
- `mipmap-{mdpi,hdpi,xhdpi,xxhdpi,xxxhdpi}/ic_launcher.png` —— 老版本用，已生成好

### 3. 日志改成折叠入口
不再是第四个 Tab 铺在外面。现在在**「球」页最底下**，一个「诊断与日志 ▸」按钮：
- 默认折叠，不占地方
- 展开后**只显示最近 8 条**，要看全部点「显示全部」（上限 200 条）
- 「导出日志」按钮放在**最上面**，不会被内容顶下去
- 文件超过 **150KB 自动砍掉前面一半**，不会越用越撑

### 4. 恢复默认
- 语速旁「语速默认 1.00」
- 音调旁「音调默认 1.00」
- 放大页「放大相关恢复默认」（倍率 2.5x、按住 260ms、补偿开）
- 球页「球相关恢复默认」（56dp、不透明 0.92、贴边开、蓝色）

### 5. 已知取舍
- **包名未改**，仍是 `com.floating.combo`，只改了显示名
- 没做主题切换，就是深色一套（按你说的，不折腾）
- LOGO 我只保证了 XML/PNG 语法正确，**画出来好不好看我看不到**，觉得丑告诉我哪儿不对
